# Data

- `raw/` holds the committed reproducible sample: the 2024 IPL final (match 1426312) with deliveries for overs 1–5 only (1 match, 67 deliveries). It has the same columns as the full files, with the space padding trimmed. It is generated by `scripts/make_sample.py` and runs end to end with `python run_pipeline.py --source sample`.
- `raw_full/` is git-ignored. Fill it with `python scripts/download_full_data.py`, which also verifies SHA-256.
- `clean_full/` is git-ignored. `run_pipeline.py --source full` writes the cleaned star tables there.

| File | Rows | Bytes | Grain |
|---|---|---|---|
| matches_2008-2024.csv | 1,095 | 223,635 | one row per match (teams, toss, result, venue, umpires) |
| deliveries_2008-2024.csv | 260,920 | 72,084,584 | one row per ball (batter, bowler, runs, extras, dismissal) |

The source is the Kaggle dataset patrickb1912/ipl-complete-dataset-20082020, mirrored at github.com/avinashyadav16/ipl-analytics. The ball-by-ball data comes from Cricsheet (ODC-BY 1.0).
